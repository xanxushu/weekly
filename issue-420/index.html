    科技爱好者周刊（第 420 期）：最分心的一年

    这里记录每周值得分享的科技内容，周五发布。

    本杂志开源，欢迎投稿。另有《谁在招人》服务，发布程序员招聘信息。合作请邮件联系（yifeng.ruan@gmail.com）。

    最分心的一年

    法国开发者亚历杭德罗·奥（Alejandro AO），是世界最大的大模型社区 Hugging Face 的布道师。

    他做了很多视频，向初学者科普 AI 知识，都放在他的 Youtube 频道。

    他的内容以实操为主，也会涉及一些原理，容易看懂。我很推荐，我的很多 AI 知识就来自这里。

    本周，他发布了一篇年度回顾，总结自己在 Hugging Face 的这一年。

    引起我共鸣的下面这段话。

    他说，2026年是他最分心的一年。“今年几乎不可能专注于一件事。同时进行多个项目，比以往任何时候都更容易。大多数时候，我手下有四到十个 Agent 同时推进三四个不同的项目。”

    大家有没有同感？

    AI 让你可以同时做几件事，越来越难专注于某一件事。

    “我每天消耗数百万 Token，尽力做好不同的项目。即使如此，仍然有一些项目被我搁置了。”

    他感到，这样是不对的。任何一个项目如果要做到优秀，都需要投入大量时间和心力打磨。分心的直接后果，就是看上去虽然成果不少，但因为时间要分给不同的项目，结果就是每个项目都浅尝辄止，做不深入。

    “我们很容易忘记，即使有 AI 编写代码，打造一个可靠的产品也绝非易事。因此，我经常会启动一些看似唾手可得的“小”项目，但这却意味着我推迟了那些我真正想做的、更有意义的项目。而这些小项目最终耗费的时间比预期要多得多。”

    AI 让人产生一种错觉，觉得只要稍微花一点点时间，构思一下提示词，就能拿到结果。于是，你就抵不住诱惑，只要脑子里蹦出的点子，都忍不住让 AI 去实现，从而将注意力从那些高优先级、急迫而重要的事情上移开。

    更糟糕的是，那些你以为最多只需要一个小时的小项目，结果不断膨胀，吞噬了比预想多得多的时间。

    正确的做法是，永远不要忘记，AI 可以让事情变得简单，但不会让时间变多。你每天的时间永远只有24个小时，并行的事情越多，就意味着每件事分到的时间就越少，就做不到把足够的时间花在最重要的事情上面。

    你的目标不是去做很多事情，而是做成最重要的事情。

    AI 越发达，每件事看上去越容易推进，就越需要我们抵制住诱惑。你要始终划分事件的优先级，筛选掉那些低优先级的事情，让工作范围更聚焦。始终把最多的时间和精力，放在最重要的事情上面。

    亚历杭德罗·奥最后许愿，希望2027年不再那么分心，更专注于自己那一两个核心项目。

    这也是我对自己的愿望，与其做加法（用 AI 做更多的事情），不如做减法（减少项目数量），借助 AI 把最重要的项目做得更大、更广、更深入。

    《GTA6》的写实主义

    《GTA5》是史上最畅销的 3A 游戏，卖出了2亿多份。它的续作《GTA6》在本周发售。

    目前总体上，这个游戏好评如潮，许多玩家都对游戏的写实主义感到震惊。它栩栩如生还原了一个虚拟的充满犯罪的美国大都市（迈阿密）。

    不仅街景逼真，而且各种情节也很接近现实。

    一个玩家讲述了自己遇到的情节。

    他正在街上开车兜风，看到前面发生了一起交通事故，一辆轿车被卡车从后面撞上。

    他赶紧下车查看，卡车司机已经逃之夭夭，轿车司机被困在车里。轿车引擎已经起火了，形势危在旦夕。他将轿车司机从车里拉了出来，后者向他表示感谢，惊恐地说自己差点丧命。

    这时，两人发现，肇事的卡车属于商业巨头撒哈拉公司（影射亚马逊公司）。轿车司机立刻说，这是他的机会！他可以起诉撒哈拉，索赔数百万美元。

    但是，他需要确凿的身体受伤证明。于是他深吸一口气，回到车里，让火焰烧着了自己的裤子，然后带着烧伤走了出来。

    他给律师打了电话。接着，救护车驶近时，他转过身来，请求那位玩家做他的证人，作为交换，他会给玩家一部分赔偿金。

    玩家当时想过要不要向他勒索更多的金额，但最终还是答应帮忙。轿车司机就通过游戏里的货币，给玩家转了几千美元。

    这个游戏就是设定这样的情节。

    一句话消息

    1、美国北卡罗来纳州的两个男子突发奇想，将两部电动滑板车绑在一起，然后把家里的沙发固定在滑板车上，变成了一辆沙发车。

    他们就坐在沙发上，操作着滑板车的把手，上街闲逛。毫不意外，很快就被警察拦下了。

    这件事报道后，引起了轰动。警察局接受采访，解释了为什么沙发车不能上街。首先，它不安全；其次，其他司机看到它会分心，导致危险驾驶。

    2、科学家在西班牙发了一具梁龙化石，人们以前一直认为这种恐龙只生活在北美洲。

    这表明，至少在这头恐龙生活的时代（1.5亿年前），西欧和北美之间是有陆地通道的，大西洋是后来形成的。

    3、为什么黑猩猩没有进化成人？最新一项研究，提出了一种可能的原因。

    研究发现，700万年前出现了一种病毒，影响了黑猩猩的大脑发育，使其无法进化出智能，而人类对这种病毒免疫。

    这给人的感觉是，好险啊。要是这个病毒再高明一点，把人类也感染了，那岂不是就没有人类社会了。

    工具

    1、sgrep

    grep 的替代品，返回语义搜索的结果。

    2、Netdata

    开源仪表板，在一个地方显示所有服务器和服务的状态。

    3、FlowVision

    macOS 的瀑布式图像浏览器。

    4、13ft

    一个开源网站，可以抓取付费墙后面的网页内容，需要自搭建。

    5、netboot.xyz

    一个操作系统的启动盘，把 Windows、Linux、BSD 的安装文件都做在一个启动盘里面。

    6、Srcbook

    类似于 Jupyter Notebook 的网页互动式笔记本，但是适用于 TypeScript 和 JavaScript。

    7、Photoshot

    开源的基于浏览器的图片编辑器。（@Abraham721 投稿）

    8、XJY Editor

    一个纯静态的网页应用，采用表格形式可视化编辑 XML / KML / JSON / YAML 文件。（@lizhaowu-79 投稿）

    9、GCS

    谷歌云的非官方命令行客户端，可以从命令行登录谷歌云的主机，进行各种操作。（@aeroxy 投稿）

    10、Waytrace（漫迹）

    开源的 iOS 应用，不需要手动操作，在后台全天记录你当天的足迹动向。（@lxyeternal 投稿）

    11、Tomoru

    跨平台桌面应用，捕获电脑或指定应用播放的声音，实时识别，并在屏幕上显示双语悬浮字幕。（@ACAne0320 投稿）

    12、crFiles

    跨平台的桌面文件管理器，最大特色是内置 Android Quick Share 协议，方便跟 Android 设备交换文件。（@wuruxu 投稿）

    13、Arke

    开源的 Windows 资源管理器替代品，特色是读取、排序、缩略图、搜索都不在界面线程上，因此打开巨大文件夹或网络共享断线，都不会卡住窗口。（@Koimsurai 投稿）

    资源

    1、周刊导航站

    网友做的周刊导航，共收入17,382个条目，可以检索。（@mwhzwh 投稿）

    2、tinybrain

    从零开始做一个中文为主的小模型，包括数据清洗、分词器、模型、预训练、SFT、蒸馏、强化学习，每一步的代码都用 PyTorch 写出来。（@cai114514114514 投稿）

    3、Lean Init IDE

    浏览器里的 Lean 4 语言练习环境，自带中英双语的入门课，从基础逻辑一直讲到归纳、素数和插入排序验证。（@3y3y3y-huaiji 投稿）

    4、浏览器工程（Web Browser Engineering）

    免费阅读下载的英文电子书，介绍网络浏览器的工作原理，演示几千行 Python 代码构建一个简单的网络浏览器。

    5、生成式 AI 基础数学入门（英文）

    免费下载的 AI 数学入门教程。

    2、不会重复的骰子

    传统的骰子往往会掷出重复的数字。

    怎样才能使得每次掷出的数字，总是不一样？一位美国数学家发明了一种新型骰子。

    这种骰子一套有五个，每个有24面，一共包含120个不同的数字。

    每个骰子掷出与上一次相同数字的概率，为1/24，那么连续5个骰子都与上一次相同，几乎是不可能的。

    所以，使用这套骰子，每次得到的结果（几乎）总是不一样的。

    1、未来的战争

    2023年，一个英国军事学家出版了一本叫做《未来的战争》的书。

    该书认为，未来的战争将越来越难打，取胜的代价越来越大。

    现在的战争完全不同于以往，由三大要素决定：传感器的覆盖范围、武器的射程以及弹药的精确度。而且，这三个要素都在不断进步。

    一旦传感器发现目标，然后弹药就能远程将其摧毁。这意味了两点。

    （1）出其不意的袭击几乎不可能了，因为攻击方的任何集结，传感器都能提前发现。

    （2）攻击只能从越来越远的远程发起，面对面的战争也不太可能了。

    现在，如果军队集结在距离前线几十公里的范围内，往往就会遭到摧毁。随着传感器和弹药的改进，这片“灰色地带”不断扩大，深入到曾经的后方。以前，军队一般在乡村的空旷地区集结，如今变得极其危险：任何兵力集结都会被侦测到，并遭到远距离摧毁。

    应对措施有下面几个。

    （1）分散和构筑防御工事，将军队分散。这有利于防御，但不利于进攻时集中兵力。

    （2）军队撤退到摄像头无法捕捉、炮弹难以击杀的地方，主要是城市。城市就像一个迷宫，到处都是掩体，很难进功城市。但是，固守城市往往有被切断补给和撤退路线的风险。

    （3）攻击敌方传感器。未来理想的军队，由高机动的士兵小组组成，这些小组负责攻击敌方传感器并部署己方传感器；同时后方的重型火炮提供火力支援。他们的目标是创造一个短暂的窗口期，让部队能够集结起来，在不被发现和歼灭的情况下夺取单一目标。

    总之，战争不太可能靠奇袭获胜了，而越来越可能是消耗战，打到一方没有足够资源为止。这就是说，战争越来越难打了，即使获胜，代码也非常巨大。
